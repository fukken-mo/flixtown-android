# Android build

Open this `android` directory in Android Studio with JDK 17 and Android SDK 36, then build the `app` module. The app ID is `com.myflixtown.tv`. This code intentionally uses a new native TV view stack instead of the previous Compose Flix Town UI.

The current source is a development checkpoint. No installable APK has passed a build or device test. The panel URL is set in `app/build.gradle`. Signing and TV artwork must be completed before a release.
